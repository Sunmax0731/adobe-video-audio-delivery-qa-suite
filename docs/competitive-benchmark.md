# Competitive Benchmark

## 比較対象

- Adobe Media Encoder
- Premiere Pro export
- Audition loudness
- Frame.io review

## 採用する評価基準

- 入力から検証、証跡、再実行までが1つの流れであること。
- 手動確認が必要な項目を warning として残せること。
- 公開前に docs、release checklist、security/privacy を確認できること。
- 編集、モーション、音声、書き出しを横断し、納品前検査を同じ証跡にする。

## 差別化

この repo は Premiere Pro panel concept + evidence CLI に閉じた最小実装だけでなく、QCDS、traceability、manual test、docs ZIP を含めた公開前の運用品質を製品の一部として扱う。
